H3VR2 存档编辑器

v0.4.0 功能
- 物品表更新至 684 条（原 666 条）：新增 18 件物品，含 SCAR-H / SCAR-L / CQC /
  弹匣 / 照门共 9 件 SCAR 系列，以及 MiniPrism / AimPro Mikro 瞄具与镜座 9 件；
  商店编辑与仓库编辑现可选择并写入这些新物品
- 新物品真实引用由游戏资源根包 extref 扫描确认（Reflex_MicroT2 用 /Item/ 命名空间）
- 附独立工具 tools/item_catalog_builder.py：游戏再更新时，用户用自己的安装包
  （zip）/ footlong.base.hdog / _root_bundle 即可读取新物品并增量更新物品表；
  命令行与图形界面两种用法，仅该工具需 UnityPy，主程序仍零 pip 依赖

历史版本
- v0.3.0：Venture 模拟器（PC 端）存档支持，自动查找 / 手动选目录 / 直接写回 + 备份
  （社区贡献者 Niko666233 通过 PR #1 提供）
- v0.2.0：预设 / 自动还原 / 玩家仓库编辑 / 收藏；修复中文路径下导出失败；
  默认包名收敛为官方包名 com.rustltd.h3vr2，仅「自动探测」后枚举设备真实包名
- v0.1.0：全参数编辑、商店物品与价格编辑、一键 USB / 局域网导出与回传
