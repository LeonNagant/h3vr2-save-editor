H3VR2 存档编辑器

改 H3VR2 单机存档里的数值、商店物品与价格、玩家仓库，并把修改真正写回设备使其生效。 Windows 便携版自带 Python 与 adb，无需安装任何依赖，解压即用。

v0.4.0 Windows 便携版 零第三方依赖 AI 生成辅助

发布日期 2026-11-26 · 自带 Python 3.10.5 与 adb · 跟着下方图示操作即可

四步改存档（跟着图做）

下面是 v0.4.0 真实界面的操作演示：红框标出要点的按钮 / 输入框， 圆圈数字是操作顺序，图片底部图例说明每步做什么。图中数值为演示用，非真实玩家存档。

先记住这一条：游戏只在「启动时」读档

运行中界面数值来自内存，跑图与结算会把旧值写回文件，直接推送会被覆盖。 所以请保持底部「回传前停止游戏并冷启动（必需）」勾选，否则修改看起来「没效果」。

1

连接设备 / 本地读取存档

USB 数据线连接并在头显点「允许 USB 调试」→ 点「刷新设备」→ 下拉框选 [USB] 设备； 不连头显时可用「查找 Venture 存档」或「手动选择存档目录」读本地存档。

图中 ① 选设备 ② 刷新设备 ③ 本地 / Venture 读取 ④ 手动选存档目录

2

一键导出存档

点底部「① 一键导出存档」，程序把头显存档导出到 exports/<时间戳>/footlong.base/， 左侧文件列表会列出导出的文件。

图中 ① 点这里导出存档到本机 ② 导出的存档文件出现在这里

3

修改内容

在「快捷编辑」页改货币 / 肉 / 金属 / 芥末等数值后点「应用快捷修改」；商店与仓库在对应标签页编辑， 改完点「② 保存到本地」写入本机副本。

图中 ① 在输入框改货币 / 肉 / 金属 / 芥末 ② 点这里应用修改

4

传回设备 / 保存到本地目录

点「③ 一键回传到头显」：程序自动停游戏 → 备份 → 推送 → 校验 → 冷启动，改动即刻生效。 本地 / Venture 存档点「②」直接写回；改坏了点「恢复最近备份」回滚。

图中 ① 保存到本地 / Venture ② 回传头显并冷启动生效 ③ 出问题可回滚

下载与运行

项目内容
当前版本v0.4.0（2026-11-26）
下载Releases · v0.4.0 → H3VR2-Save-Editor-v0.4.0-Windows-Portable.zip（ASCII 资产名，解压后目录与说明均为中文）
运行解压整个压缩包（支持中文路径）→ 双击 启动存档编辑器.bat；窗口没出现就双击 启动-调试模式.bat 看报错
环境Windows 10/11 64 位 + Meta Quest（开发者模式 / USB 调试）；也支持 PC 端 Venture 模拟器
依赖无需安装：自带 Python 3.10.5（含 tkinter）与 adb，零第三方 pip 依赖

能改什么

数值

货币、肉、金属、芥末、经验、血量、游玩统计；一键弹匣补满。

商店

684 种物品可选，改出售物品 / 售价 / 分区；增删货位、打折、统一定价。

仓库

多页 12×8 网格，换物品、改占格与位置、复制 / 删除 / 新增槽位。

预设 / 收藏

保存编辑内容为预设，导出新存档一键还原；收藏快速定位并批量加入。

全部字段

「全部参数（树）」逐字段改、「原始 JSON」整段编辑、「字段说明」生成中文说明。

物品表生成器

游戏更新后从自己的安装包读取新物品、增量更新物品表，让修改器认识新枪新物件。

非官方 · 仅用于自己的单机存档

与游戏开发者、发行方、平台方无关联，只读写自己的单机存档 JSON，不修改游戏本体， 不绕过授权或内购，不收集或上传任何数据。默认且仅列官方包名 com.rustltd.h3vr2。
