H3VR2 存档编辑器

面向 Meta Quest 上 H3VR2 单机存档的非官方第三方编辑工具： 改全部参数、商店出售物品与价格、玩家仓库物品；一键导出、一键回传，并让改动真正生效。

功能

从一份 gzip 压缩的 JSON 存档里，把资源、经验、商店货位、仓库槽位 全部变成可读、可编辑的字段；并把「改完不生效」的链路一并处理好。

全部参数

树形页逐字段双击改值、右键增删节点；「原始 JSON」页可整段编辑，1296 个叶子字段都能改。

商店编辑

列出全部货位，搜索 666 种物品改出售物品、售价与分区；增删货位、打折、统一定价。

仓库编辑

多页 12×8 网格：换物品、改占格、清空组件、复制 / 删除 / 新增槽位，页满自动开新页。

预设与自动还原

编辑内容存在独立的 presets.json，导出新存档后一键还原，不必重新编辑。

收藏

常用物品加星，物品选择框「只看收藏」快速定位，可批量加入商店或仓库。

一键导出 / 回传

USB 或无线 adb 导出到本机；回传自动停游戏 → 备份 → 推送 → 校验 → 冷启动读档。

Venture 模拟器

v0.3.0 新增：自动查找 PC 端 Venture 里的存档并直接写回（无需 adb），保存前自动备份。

使用方法

便携版解压后双击「启动存档编辑器.bat」即可；连接头显后按三步操作。

1

连接并导出

USB 数据线连接（或先「USB→启用无线调试」），点「刷新设备」选中头显， 再点「① 一键导出存档」。

2

编辑

7 个标签页里改数值、商店、仓库；或直接套用预设。点「② 保存到本地」写盘。

3

回传生效

点「③ 一键回传到头显」。程序强制停止游戏、备份、推送、chmod 666、 md5 校验并冷启动。

为什么必须停游戏再冷启动

游戏只在启动时读档；运行中界面数值来自内存，跑图与结算会把 内存旧值写回文件，直接推送会被覆盖。底部「回传前停止游戏并冷启动」开关 默认开启，请勿关闭。出问题可点「恢复最近备份」回滚。

预设：导出新存档后不用重新编辑

每次从设备重新导出的都是设备上的新内容，之前改好的商店与仓库不会 自动跟过来。预设把「编辑内容」单独存到程序目录，与存档分离。

怎么用

  • 改好商店或仓库 → 点「保存当前为预设」。
  • 之后导出新存档 → 选预设点「一键应用（替换）」；或在「收藏与预设」页设为自动应用。
  • 「追加物品」在不删除现有货位 / 槽位的前提下批量加入。
  • 预设可导出成一份 JSON 分享，也可用记事本直接编辑。
{
  "version": 2,
  "settings": {
    "store_auto_preset": "我的常用商店",
    "store_auto_mode": "replace"
  },
  "store_presets": {
    "我的常用商店": {
      "boxes": [
        {"item": "M4A1", "price": 1,
         "sectionID": "basics"}
      ]
    }
  },
  "inventory_presets": {
    "常用补给": {
      "items": [{"item": "MapR",
                 "size": [1, 1]}]
    }
  },
  "favorites": ["MapR"]
}

如果设备上的包名与官方不同

点界面「自动探测」，程序会枚举设备 /sdcard/Android/data 下真实存在的游戏包名与存档槽 （Profile0 = Slot 1），列出后由你手动选中并「保存配置」。 这是设备侧的通用兼容能力，不是对任何第三方发行版的推荐。

  • 程序启动时不会静默枚举设备包名；
  • 默认配置、下拉框初始值与兜底候选都只有官方包名；
  • 配置里已指定包名时，导出 / 回传不会在未经你操作的情况下自动切换目标。
